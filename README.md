# AI PDF Summarizer

A mobile app built with React Native and Expo that lets you upload a PDF and instantly get an AI-generated summary and translation.

## Features

Upload any PDF from your device
AI-powered summarization of the document content
Translation support for multilingual output
Clean mobile UI built with Expo Router

## Tech Stack
* Framework: React Native + Expo
* Navigation: Expo Router
* File Handling: expo-document-picker
* AI: lightweight LLM integration via prompt engineering

## How It Works 

1. The user selects a PDF using the device file picker
2. The text content is extracted from the PDF
3. The text is sent to an AI model via a prompt
4. The app displays the summary and translated output
